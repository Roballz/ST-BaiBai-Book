# 自动隐藏楼层开关

入口：设置 → 摘要设置 → 自动隐藏楼层。默认开启，旧设置自动兼容。

- 开启时保留原有规则：窗口外已覆盖原文隐藏，窗口内/不再覆盖的插件隐藏楼层恢复。
- 关闭时自动摘要、字段填写、时间标签和积压拦截仍由“启用自动摘要”控制；停止全部自动隐藏同步，不隐藏新楼层，也不取消已有隐藏。手动触发的隐藏同步入口同样遵守此开关。
- 未隐藏楼层继续发送原文，其普通历史摘要不注入；向量/BM25 召回也排除当前聊天这些可见叶子，避免重复发送摘要。已有隐藏楼层仍可由摘要代表，知识库及旧档范围保持原规则。
- 切换开关只刷新注入和失效召回缓存，不立即重排隐藏状态；重新开启后在下一次隐藏同步时恢复原有窗口规则。已经提交给宿主执行的单次 slash 命令无法撤回，后续批次会检查开关。

实现修改约 30 行，测试约 60 行，复用已有“叶子仅在原文隐藏时启用”的普通摘要选择逻辑。
