# 物品整改试用分支

基于 `32dbb48`，分支 `codex/item-keywords-presence`。包含源码与已构建的 `dist`，安装时选择此分支。

- 编辑物品可填写关键词、持有人、历史起源。关键词用逗号、顿号、分号或换行分隔。
- 关键词仅用于触发，不出现在发给正文 LLM 的物品信息中；摘要填表仍可读取关键词。持有人、历史起源随完整设定注入。
- 星标：物品完整设定常驻物品区域，不受寄存位置限制。
- 隐藏：未触发时不出现于物品正文或寄存简表；关键词命中后完整展开。隐藏与星标互斥。
- 物品页面分重要物品、次要物品、隐藏物品三个独立折叠区，默认收起并显示组内数量。显示模式修改立即保存，但现有条目留在原组；右上角加号左侧的刷新按钮才按最新模式重分组，不重置各组展开状态。加号展开手动添加栏。
- 普通物品保持原有随身/寄存行为，关键词命中时也展开完整信息。
- 匹配复用生活档案的最近 6 条非空正文、最多 4000 字上下文；区分大小写的子串匹配，任一关键词命中即可，没有物品数量上限。
- 仍遵守仅摘要模式、物品/场景注入开关。隐藏控制结构化物品注入，不删除原始剧情、历史摘要或物品变动旁注；摘要副 API 仍读取完整物品事实以更新档案。
- AI 用 `keywords`、`holder`、新增的 `history` / 增量 `historyAppend` 填表。AI 输出的常驻/隐藏控制字段被丢弃，历史始终追加；手动编辑可修正或清空历史全文。
- 新字段随叶子保存，改名、重载和带数据新聊天保留；旧记录无需迁移。没有有效摘要叶子时仍不能手动添加。
